图腾 打开工作台

不写代码，做一个会画图的 AI

你不需要看懂任何代码。打开 Claude Code 或 Codex，把下面的话一句一句发给它，它写代码，你负责拍板。全程大约两小时，最后你会拿到一个能发给别人的网址。

你做的事

  • 去后台点一下，拿一把密钥
  • 把下面的话复制给 AI
  • 看图，说好看还是不好看
  • 决定要不要给网页加把锁

AI 做的事

  • 写全部代码
  • 装环境、装依赖
  • 部署、发布、排错
  • 出问题了自己改
0

先准备三样东西

这三件事 AI 替你做不了，因为都要你本人登录。加起来大概十分钟。

一、装 Claude Code 或 Codex。随便哪个都行，就是那个能在你电脑上帮你写代码的 AI。装完在你想放项目的地方打开它。

二、拿一把密钥。打开 ZooWork App，走 Settings → API Keys → Create API Key，起个名字比如 my-agent，然后立刻复制那串 zct_ 开头的字符。

这串东西只会出现一次关掉页面就再也看不到了。当场存到密码管理器里。真丢了也不用慌，回同一个页面点 Rotate 换一把新的就行。

另外它很值钱，不要粘到聊天里。只写进项目中被 Git 忽略的 .env 文件。

三、注册一个 Cloudflare 账号。去 Cloudflare Dashboard 注册并登录。这是最后用来把网页和 API 发出去的地方。

1

让它把地基搭好

第一句话，让 AI 建项目、装好东西、验证密钥能用。

复制这段发给 Claude Code / Codex
我想做一个会画图的 AI Agent，跑在 ZooWork 这个平台上，最后要做成网页发到公网。我不懂代码，全部交给你，遇到要我决定的事再问我。 先做第一步： 1. 在当前目录建一个新项目 2. 按 https://zoowork.ai/docs/zh/get-started/quickstart 安装官方 ZooWork Skill，写代码前先读它，别凭记忆写 3. 安装 @zoowork-ai/sdk 4. 在项目里准备好 ignored 的 .env，变量名用 ZOOWORK_API_KEY。不要读取或打印 key；文件准备好后停下来让我自己填写 我说填好之后，用 listModels() 确认密钥可用，然后告诉我结果。
你应该看到它最后会列出一串模型名字，类似 litellm/claude-sonnet-5 这样的。看到列表就说明密钥没问题，可以往下走。
如果它说密钥无效回后台重新复制一次，或者直接 Rotate 换一把新的，然后自己更新 .env。只告诉 AI“我已经更新好了”，不要把 key 发进聊天。
2

告诉它你想要什么本事

这一步决定你的 AI 会干什么。这里以「画吉祥物标志」为例，用一份现成的开源规范。

下面这段里，中间那几条「必须写清楚的」是别人已经踩过的坑。你不用懂它们的意思，原样复制过去就行，AI 看得懂。

复制这段接着发
很好，接着做第二步。 我想让它会画 IP 吉祥物 Logo。用这份现成的开源规范： https://github.com/s1dashu/ip-as-logo-skill 把它做成 Agent 的技能，规范本身一个字都不要改。 另外给 Agent 写一份人设，人设里必须写清楚下面几条，这些是别人踩过的坑： - 画图只能用沙箱里那个同步的命令行脚本，绝对不许用异步的 image_generate 工具，否则会一直空等，最后一张图都交不出来 - 每画完一张，必须重新打开这张图看一遍再评价，不许没看就说合格 - 六张全说合格是不正常的，判废不丢人，隐瞒才丢人 - 判废的自动重画一次，不要停下来问我要不要重画 - 每张画完必须发布产物。这条写成命令句，不许写成「如果有这个工具就用，没有就跳过」，那样它会直接跳过 - 出图用 1024 见方 写完先给我看一眼人设，我确认后再往下。
你应该看到它会把人设念给你听。你不用逐字读，扫一眼确认里面确实有「不许用异步工具」「必须自己看图」「判废自动重画」这几条就行。
想做别的？把上面那个规范链接换成别的就行。写文案、做数据分析、剪视频，流程完全一样，只有这一步换内容。
3

让它跑起来

把 Agent 送上云，并且当场试一次。

复制这段接着发
可以，按这份人设部署上云。 注意几件事： - 每一步做完都要读回来确认真的成了，有几个调用即使没成也会返回成功 - 用固定的幂等键，不要每次部署都建一个新的 Agent 出来 - 部署好之后，第一次碰它必须是发一句对话，不要先跑命令去看环境 部署完直接试一次：让它给一个做冷萃咖啡的品牌设计吉祥物，客群是城市白领，要清爽、有点酷、不甜腻。把它给的方向念给我听。
你应该看到它会给你三个不同的方向，每个一句话，比如「酷企鹅 · 呼应冷萃的冷感 · 圆头小企鹅加短翼」。然后问你要不要开始画六张。
如果它直接开始画了说明人设里「先给方向再动笔」那条没生效。跟它说：
它跳过了给方向这一步，直接开始画了。人设里加一条：必须先给三个方向、等我点头才能动笔。
4

让它真的画出来

这一步最花时间，六张图加上返工大概十五分钟。中间你可以去泡杯咖啡。

复制这段接着发
方向可以，让它画六张。 画完之后告诉我：一共画了几张、几张合格、几张返工了、返工的是因为什么。
你应该看到它报告类似「六张里只有一张合格，五张返工，问题分别是四角有杂色块、耳朵尖了、主体摆得太居中」这样的具体理由，而不是笼统的「都符合规范」。

返工之后总数会变多，比如六张变十二张（原图加重画版都留着），这是对的。
如果它说六张全部合格这几乎不可能，说明它根本没看图。跟它说：
六张全合格不太可能。请你逐张重新打开图片看一遍，对照规范认真核对，尤其看四个角有没有杂色块、有没有尖角、主体是不是从下角出画。然后重新给结论。
如果它卡住很久没动静大概率是用了异步的画图工具在空等。跟它说：
你是不是用了异步的 image_generate 工具？换成沙箱里那个同步的命令行脚本，一张一张画，画完再画下一张。
5

看图，说好看还是不好看

这是只有你能做的一步。前面它自己检查的是「有没有违反规范」，好不好看得你说了算。

复制这段接着发
把图给我看看。

看完之后你可以直接用大白话继续，不用讲专业术语：

  • 「第二个我喜欢，但颜色太暗了，换亮一点的」
  • 「第一个方向再画六个不一样的」
  • 「都不太行，换个动物试试」
  • 「把背景换成粉色」
一个判断标准把图缩到手机 App 图标那么小，还认得出是什么，才算好标志。放大好看不算数。你可以让它直接缩给你看：
把这几张缩到 App 图标那么小给我看，看看还认不认得出。
6

做成网页发出去

到这里只有你能在终端里用它。这一步做成网页，别人也能用。

复制这段接着发
很好，现在做成一个网页，发布到公网上。 要求： - 我的密钥只能待在服务器上，绝对不能出现在网页里，别人看网页源码也看不到 - 页面上不要出现代码、模型名、编号这类我看不懂的东西，说人话 - 手机上也要好用 - 画图要好几分钟，别用一个请求从头等到尾，会超时 发布用 Cloudflare Workers。密钥只能放在 Worker secret 里。发好之后把网址给我。
你应该看到它给你一个 Cloudflare Workers 地址或你自己的域名。用手机打开试试，能建项目、能对话、能看到图，就成了。
如果它中途让你登录 Cloudflare正常，浏览器会自己弹出来。完成登录和授权后让 AI 继续部署。
7

决定要不要加把锁

刚发出去的网址是完全公开的，任何人拿到都能打开，也就意味着任何人都能用你的额度画图。

想留个门槛就跟它说：

复制这段接着发
给这个网页加个密码，只有知道密码的人能打开。密码我自己定，你告诉我在哪设。
验证的时候一定要用正式网址预览链接和正式网址的保护规则不一样。别拿预览链接测出来的结果推断正式的。让它当着你的面用正式网址试一次，确认没密码打不开。

任何时候卡住了

你不需要看懂错误信息。把下面这句发过去就行。

万能句卡住时发这个
报错了，你先自己看看是什么问题，能修就直接修，不要问我技术细节。如果需要我做什么（比如去某个网站点个按钮、给你一个密码），直接告诉我点哪里就行。

另外两句也很有用：

它说做完了但你没看到效果
你说做完了，但我这边看不到效果。你自己实际验证一遍，把你验证的过程和结果告诉我，不要只说「已完成」。
它开始跟你讲技术细节
这些我听不懂。用大白话告诉我：现在是好了还是没好，我下一步要做什么。

就这些

回头看，你真正做的只有四件事：去后台拿了一把密钥、复制了七段话、看图说了几句好看不好看、决定要不要加密码。剩下的都是它干的。

把第 2 步那个规范链接换掉，同一套流程能做出完全不同的 AI。
